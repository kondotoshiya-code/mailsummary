# 【完全無料】Google Apps Script でメールサマリーを作る手順

プログラミング不要・サーバー不要・**完全無料**。
すべてブラウザの中で完結します。やることは大きく4つだけです。

1. コードを貼り付ける
2. 鍵を2つ登録する（Gemini APIキー・Google Chat Webhook）
3. 1回だけ「許可」する
4. 自動実行の時間（8/12/17時）を登録する

所要時間の目安：**20〜30分**。

---

## 準備するもの（2つ）

### ① Gemini の無料 API キー
1. https://aistudio.google.com/app/apikey を開く（**kondo.toshiya@lm-sg.com** でログイン）
2. 「**Create API key（APIキーを作成）**」をクリック
3. 表示された `AIza...` で始まるキーをコピーして控える
   - ※ 支払い登録は不要。無料で使えます。

### ② Google Chat の Webhook URL
1. 通知したい Google Chat の**スペース**を開く（自分用に新規スペースを作ってもOK）
2. スペース名をクリック →「**アプリと連携**」→「**Webhook**」
3. 「**Webhook を追加**」→ 名前（例：メールサマリー）を付けて作成
4. 表示された URL（`https://chat.googleapis.com/v1/spaces/.../messages?key=...`）をコピーして控える

---

## ステップ1：スクリプトを作ってコードを貼る

1. https://script.google.com/ を開く（同じアカウントで）
2. 左上「**新しいプロジェクト**」をクリック
3. 既定で出ている `function myFunction() {}` を**全部消す**
4. このリポジトリの [`apps-script/Code.gs`](../apps-script/Code.gs) の**中身を全部コピー**して貼り付ける
5. 左上のプロジェクト名（「無題のプロジェクト」）を `メールサマリー` などに変更
6. フロッピーのアイコン（保存）を押す

---

## ステップ2：鍵を2つ登録する

1. 左メニューの歯車「**プロジェクトの設定**」をクリック
2. 下のほうの「**スクリプト プロパティ**」→「**スクリプト プロパティを追加**」
3. 次の2つを登録する（プロパティ名は**正確に**）

   | プロパティ | 値 |
   | --- | --- |
   | `GEMINI_API_KEY` | 準備①の `AIza...` キー |
   | `CHAT_WEBHOOK_URL` | 準備②の Webhook URL |

4. 「**スクリプト プロパティを保存**」を押す

> 🔒 鍵はコードに書かず、ここ（プロパティ）に入れるので安全です。

---

## ステップ3：動作テスト＆初回の許可

1. 左メニューの「**エディタ**」（< > アイコン）に戻る
2. 画面上部の関数選択（プルダウン）で **`runTestNow`** を選ぶ
3. 「**実行**」を押す
4. **初回だけ**「承認が必要です」と出る → 「**権限を確認**」→ 自分のアカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら
     「**詳細**」→「**（プロジェクト名）に移動**」→「**許可**」
   - （自分が作った自分用スクリプトなので安全です）
5. 数秒〜十数秒後、**Google Chat に「📬 メールサマリー（テスト）」が届けば成功！** 🎉
   - 直近24時間のメールを対象にテストします

---

## ステップ4：毎日 8/12/17 時の自動実行を登録

1. 関数選択のプルダウンで **`installTriggers`** を選ぶ
2. 「**実行**」を押す
3. これだけで「毎日 朝8時・昼12時・夕方17時（日本時間）」の自動実行が登録されます

確認したい場合：左メニューの目覚まし時計アイコン「**トリガー**」を開くと、
`mailSummary` のトリガーが3つ並んでいます。

✅ これで完成です。あとは毎日自動で届きます。何もしなくてOK。

## よくある質問・つまずき

| 症状 | 対処 |
| --- | --- |
| Chat に届かない | `CHAT_WEBHOOK_URL` のコピー漏れ／別スペースを見ていないか確認 |
| `スクリプト プロパティに…登録してください` | ステップ2の名前のスペルを確認（`GEMINI_API_KEY` 等） |
| `Gemini API エラー` | APIキーが正しいか、`GEMINI_MODEL` の名前を確認 |
| 時間どおりに来ない | Apps Script の時間トリガーは指定時刻から1時間以内のどこかで動きます（仕様） |
| 通知が多すぎ/少なすぎ | `Code.gs` の検索条件（`fetchEmails_` 内の `query`）を調整 |
| 要約をもっと細かく | `Code.gs` の `classifyWithGemini_` のプロンプト文を編集 |

## 仕組みのメモ

- 各実行は「前回スロット以降」のメールだけが対象（朝は前日17時〜の夜間分をカバー）。
  そのため同じメールが何度も通知されることはありません。
- Gmail は GmailApp（あなたのアカウント権限）で読むため、Cloud Console もトークンも不要です。
- 料金：Apps Script・Gmail・Google Chat Webhook はすべて無料。Gemini も無料枠で動きます。
