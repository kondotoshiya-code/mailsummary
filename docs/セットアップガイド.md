# はじめての方向け セットアップガイド

このガイドは、**プログラミングの経験がない方**でも、画面の指示どおりに進めれば
「毎日メールのサマリーが Google Chat に届く」状態になるように作りました。

- パソコンへのインストールは **不要**（すべてブラウザの中で完結します）
- 所要時間の目安：**40分〜1時間**（初めての場合）
- 途中で分からなくなっても大丈夫。Claude に「○○のところで止まりました」と聞けば続きを案内します

---

## 完成までの全体像（6ステップ）

| ステップ | やること | だいたいの時間 |
| --- | --- | --- |
| 0 | コードを GitHub に保存する（書き込み許可） | 3分 |
| 1 | Google にアプリを登録する（Gmail を読む許可の土台） | 15分 |
| 2 | 「合言葉（リフレッシュトークン）」を取得する | 10分 |
| 3 | Google Chat の通知先（Webhook）を用意する | 5分 |
| 4 | Claude の API キーを取得する | 5分 |
| 5 | 取得した値を GitHub に登録する（金庫＝Secrets） | 10分 |
| 6 | テスト実行して、Chat に届くか確認する | 3分 |

> 💡 **用語のイメージ**
> - **GitHub**：プログラムの保管庫＆自動実行をしてくれる場所
> - **Secrets（シークレット）**：パスワードなどを安全にしまう「金庫」
> - **API キー / トークン**：サービスにアクセスするための「合言葉」

## ステップ0：コードを GitHub に保存する

いまコードは準備できていますが、GitHub への「書き込み」が許可されていないため、
まだ保存（プッシュ）できていません。次の操作で許可してください。

1. ブラウザで https://github.com/settings/installations を開く
2. 一覧から **Claude**（または連携アプリ）をクリック
3. **Repository access** の項目で `mailsummary` リポジトリが選ばれているか確認
   - 入っていなければ「Only select repositories」で `mailsummary` を追加
4. 権限に **Contents（コンテンツ）＝ Read and write** が含まれていることを確認して保存

許可できたら、Claude に「**再試行して**」と送ってください。保存（プッシュ）を実行します。

> これ以降のステップ（1〜6）は、コードの保存を待たずに**並行して進めてOK**です。

## ステップ1：Google にアプリを登録する

Gmail を「読み取り専用」で安全に読むための土台を作ります。

### 1-1. プロジェクトを作る
1. https://console.cloud.google.com/ にアクセスし、**kondo.toshiya@lm-sg.com** でログイン
2. 画面上部の青いバーにあるプロジェクト選択（左上のプルダウン）をクリック
3. 右上の「**新しいプロジェクト**」→ 名前を `mailsummary` などにして「作成」
4. 作成後、もう一度プルダウンから `mailsummary` を選択しておく

### 1-2. Gmail API をオンにする
1. 左上のメニュー（≡）→「**API とサービス**」→「**ライブラリ**」
2. 検索欄に `Gmail API` と入力して開く
3. 青い「**有効にする**」ボタンを押す

### 1-3. 同意画面を設定する
1. 左メニュー →「**API とサービス**」→「**OAuth 同意画面**」
2. User Type は「**外部**」を選んで「作成」
   - （会社の管理者設定によっては「内部」しか選べないこともあります。その場合は「内部」でOK）
3. アプリ名（例：`mailsummary`）、ユーザーサポートメール、開発者の連絡先メールに
   自分のメールアドレスを入れて「保存して次へ」を繰り返す
4. 「**テストユーザー**」の画面で「ADD USERS」→ **kondo.toshiya@lm-sg.com** を追加して保存
   - （ここを忘れると後でログインできません。重要）

### 1-4. 認証情報（鍵）を作る
1. 左メニュー →「**API とサービス**」→「**認証情報**」
2. 上部「**＋認証情報を作成**」→「**OAuth クライアント ID**」
3. アプリケーションの種類で「**デスクトップアプリ**」を選び、名前を付けて「作成」
4. ポップアップに表示される **クライアント ID** と **クライアント シークレット** を、
   この後すぐ使うのでメモ帳などに控えておく
   （または「JSON をダウンロード」を押して保存）

✅ ここまでで「Google にアプリを登録」は完了です。

## ステップ2：合言葉（リフレッシュトークン）を取得する

ここがいちばん難しそうに見えますが、**ブラウザの中のターミナル（Cloud Shell）**を使えば、
パソコンに何もインストールせずにできます。落ち着いてどうぞ。

1. https://console.cloud.google.com/ の右上にある **「>_」アイコン**（Cloud Shell をアクティブにする）をクリック
   - 画面下部に黒い画面（ターミナル）が開きます。「続行」を押す
2. 黒い画面に、次の1行を**コピーして貼り付け**、Enter キーを押す
   （貼り付けは Ctrl+V、Mac は Cmd+V。`YOUR_ID` と `YOUR_SECRET` は後で置き換えます）

   ```bash
   pip install --quiet google-auth-oauthlib
   ```

3. 次に、ステップ1-4で控えた値を使って、以下を1行ずつ貼り付け＆Enter
   （`ここにクライアントID` などを、自分の値に置き換えてください）

   ```bash
   export CID="ここにクライアントID"
   export CSECRET="ここにクライアントシークレット"
   ```

4. 最後に、次のかたまりを丸ごとコピーして貼り付け、Enter を押す

   ```bash
   python3 - <<'PY'
   import os
   from google_auth_oauthlib.flow import InstalledAppFlow
   cfg = {"installed": {
       "client_id": os.environ["CID"],
       "client_secret": os.environ["CSECRET"],
       "auth_uri": "https://accounts.google.com/o/oauth2/auth",
       "token_uri": "https://oauth2.googleapis.com/token",
       "redirect_uris": ["urn:ietf:wg:oauth:2.0:oob"]}}
   flow = InstalledAppFlow.from_client_config(
       cfg, ["https://www.googleapis.com/auth/gmail.readonly"],
       redirect_uri="urn:ietf:wg:oauth:2.0:oob")
   url, _ = flow.authorization_url(access_type="offline", prompt="consent")
   print("\n▼このURLをブラウザの別タブで開いて許可してください:\n" + url + "\n")
   code = input("表示されたコードを貼り付けて Enter: ").strip()
   flow.fetch_token(code=code)
   print("\n==== これをメモしてください ====")
   print("GMAIL_REFRESH_TOKEN =", flow.credentials.refresh_token)
   print("================================")
   PY
   ```

5. 表示された **URL を別タブで開く** →（kondo.toshiya@lm-sg.com で）ログイン
   - 「このアプリは Google で確認されていません」と出たら、
     「**詳細**」→「**(安全でないページに移動)**」→ 自分のアプリなので進んでOK
6. アクセスを「**許可**」すると、画面に**コード**が表示されます。それをコピー
7. Cloud Shell の黒い画面に戻り、コードを貼り付けて Enter
8. `GMAIL_REFRESH_TOKEN = 1//0g...` のような長い文字列が表示されます。**これをメモ**

> 控えるもの（3つ）：
> - **GMAIL_CLIENT_ID**（ステップ1-4のクライアントID）
> - **GMAIL_CLIENT_SECRET**（ステップ1-4のクライアントシークレット）
> - **GMAIL_REFRESH_TOKEN**（いま表示された長い文字列）

✅ これで「Gmail を読む合言葉」がそろいました。

## ステップ3：Google Chat の通知先（Webhook）を用意する

メールサマリーを届けたい Google Chat の場所を決めます。

1. ブラウザで Google Chat（https://chat.google.com/）を開く
2. 通知を受け取りたい**スペース**を開く（自分だけの確認用に新しいスペースを作ってもOK）
3. スペース名をクリック →「**アプリと連携**」→「**Webhook**」（または「Webhook を管理」）
4. 「**Webhook を追加**」→ 名前を `メールサマリー` などにして「保存」
5. 表示された **Webhook の URL をコピー**してメモ
   - `https://chat.googleapis.com/v1/spaces/.../messages?key=...` のような形

> 会社のポリシーで「Webhook」が出てこない場合は、Workspace 管理者に
> 「Google Chat の incoming webhook を許可してほしい」と相談してください。

✅ 控えるもの：**GOOGLE_CHAT_WEBHOOK_URL**

## ステップ4：Claude の API キーを取得する

メールを読んで分類・要約してくれる頭脳の部分です。

1. https://console.anthropic.com/ にアクセスしてログイン（アカウントが無ければ作成）
2. 支払い方法の登録が必要です（少額。Haiku モデルは1通あたり非常に安価です）
3. 左メニューの「**API Keys**」→「**Create Key**」
4. 表示された `sk-ant-...` で始まるキーを**コピー**してメモ
   - ⚠️ この画面を閉じると二度と表示されません。必ず控えてください

✅ 控えるもの：**ANTHROPIC_API_KEY**

## ステップ5：取得した値を GitHub の金庫に登録する

ここまでで控えた5つの値を、GitHub の安全な保管場所（Secrets）に入れます。
**この値はコードには書きません。**金庫にだけ入れるので安全です。

1. ブラウザで `https://github.com/kondotoshiya-code/mailsummary` を開く
2. 上部の「**Settings**」タブをクリック
3. 左メニュー →「**Secrets and variables**」→「**Actions**」
4. 「**New repository secret**」を押して、次の5つを**1つずつ**登録する
   （Name に下記の名前、Secret に控えた値を貼り付け→「Add secret」）

   | Name（名前。正確に） | Secret（値） |
   | --- | --- |
   | `GMAIL_CLIENT_ID` | ステップ1-4のクライアントID |
   | `GMAIL_CLIENT_SECRET` | ステップ1-4のクライアントシークレット |
   | `GMAIL_REFRESH_TOKEN` | ステップ2で取得した長い文字列 |
   | `ANTHROPIC_API_KEY` | ステップ4の `sk-ant-...` |
   | `GOOGLE_CHAT_WEBHOOK_URL` | ステップ3の URL |

   > 名前は**大文字・アンダースコアまで正確に**入力してください（コピペ推奨）。

✅ 5つ登録できたら、準備完了です。

## ステップ6：テスト実行して確認する

いよいよ動かします。まずは手動で1回試します。

1. `https://github.com/kondotoshiya-code/mailsummary` を開く
2. 上部の「**Actions**」タブをクリック
3. （初回は「I understand my workflows, go ahead and enable them」が出たら有効化）
4. 左の一覧から「**Mail Summary**」を選ぶ
5. 右側の「**Run workflow**」ボタンを押す
6. 「何時間前まで遡るか」に `24` と入力して、緑の「**Run workflow**」を押す
   - これで「直近24時間のメール」でテストできます
7. 1〜2分待つと実行が始まります。行をクリックすると進捗が見えます
8. **Google Chat に「📬 メールサマリー」が届けば成功！** 🎉

うまくいったら、あとは**毎日 朝8時・昼12時・夕方17時（日本時間）に自動で届きます**。
何もしなくて大丈夫です。

## うまくいかないときは（よくあるつまずき）

| 症状 | 原因と対処 |
| --- | --- |
| 実行が赤い×になる | 行をクリック→赤い箇所の英語を Claude に貼り付けて聞いてください |
| `環境変数 ... が設定されていません` | ステップ5の Secret の**名前のスペルミス**。表の名前と完全一致か確認 |
| `invalid_grant` 系のエラー | リフレッシュトークンの期限切れ。ステップ2をもう一度実行して再登録 |
| Chat に届かない | ステップ3の Webhook URL のコピー漏れ／別スペースを見ている可能性 |
| Google のログインで弾かれる | ステップ1-3の「テストユーザー」に自分のメールを追加したか確認 |
| 時間どおりに来ない | GitHub の自動実行は数分〜十数分ずれることがあります（仕様。気長に） |

困ったら、エラー画面の文章をそのまま Claude に貼り付けて
「これはどういう意味？どうすればいい？」と聞いてください。続きを一緒に解決します。
